# Business Operation Review

Este é um projeto de análise de operações de negócio com interface web desenvolvida em React/TypeScript.

## Estrutura do Projeto

```
business_operation_review/
├── frontend/          # Aplicação React/TypeScript
│   ├── src/          # Código fonte
│   ├── public/       # Arquivos públicos
│   ├── package.json  # Dependências do projeto
│   └── README.md     # Documentação do frontend
└── README.md         # Este arquivo
```

## Tecnologias Utilizadas

- **Frontend**: React, TypeScript, Vite
- **Estilização**: CSS
- **Banco de Dados**: Supabase
- **Build Tool**: Vite

## Como Executar

### Pré-requisitos

- Node.js (versão 16 ou superior)
- npm ou yarn

### Instalação

1. Clone o repositório:
```bash
git clone <url-do-repositorio>
cd business_operation_review
```

2. Instale as dependências do frontend:
```bash
cd frontend
npm install
```

3. Execute o projeto:
```bash
npm run dev
```

O projeto estará disponível em `http://localhost:5173`

## Funcionalidades

- Dashboard de análise de operações
- Sistema de login
- Análise de timesheet
- Interface responsiva
